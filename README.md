# Daily Drafts

Phone-friendly PWA for @UpgradeAmerican X framework drafts.

## Use
1. Open the site in Chrome
2. Install app / Add to Home screen
3. Rewrite frameworks in your voice, then post yourself

## Add a day
Copy `public/drafts/TEMPLATE.json` to `public/drafts/YYYY-MM-DD.json` and add the date to `public/drafts/index.json`.

## Deploy (Vercel free + GitHub)
Import this repo in Vercel and click Deploy. No extra settings needed for the static build.
